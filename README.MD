 
# Student Management System

This is my Python project for managing students and courses.

I used Python and SQLite to create this program.

## What My Program Does

1. Add a new student
2. Show all students
3. Add a new course
4. Show all courses
5. Enroll a student in a course
6. Show all enrollments

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Type: python app.py
4. Press Enter.
5. Choose a number from the menu.

## Technologies and Tools Used

- Python
- SQLite
- Visual Studio Code (VS Code)
- Object-Oriented Programming (OOP)
